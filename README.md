This is GraphQL server that illustrate search's schema (80-90% accuracy compared to production one).
You could play around with query and get some sense how response would be.
In addition, I roughly wrote this app, so the code stil does not ready for production used.

## Prerequisites

Node 10

## Getting Started

Installing dependencies
```
npm install
```

Spin-up local server
```
npm start
```

Enjoy! 
```
http://localhost:4000/graphql 
```

## Built With

* [Express](https://github.com/expressjs/express) - Web framework for Node.js
* [Apollo-Server](https://github.com/apollographql/apollo-server) - Framework for GraphQL
